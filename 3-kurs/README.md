# 3. Сам курс

Те, що бачить учень. Два незалежні курси, спільний глосарій і емулятори.

| Тека | Що всередині |
|---|---|
| [course-1-basics](course-1-basics/) | курс 1: базовий інсталятор СБ, 9 модулів |
| [course-2-sunell](course-2-sunell/) | курс 2: обладнання Sunell, 8 модулів |
| [shared](shared/) | глосарій, чек-лист першого обʼєкта, шаблони портфоліо і сертифіката |
| [emulators](emulators/) | емулятори камери, реєстратора і роутера |

## Як влаштований модуль

Кожен модуль це тека з трьох файлів:

- `lesson.md` - урок;
- `practice.md` - практика;
- `checklist.md` - чек-лист самоперевірки.

Модуль 1 курсу 1 має ще `self-test.md`, підсумковий - `next-steps.md`.

## Емулятори

Працюють у браузері, реальне обладнання не потрібне.

- `camera-web-ui.html` - точна копія веб-інтерфейсу камери Sunell IPR57/20AKDN/T/Z2.7-12/13, усі 64 розділи зняті з живого пристрою. Зібраний скриптом з `emulators/_source-camera-sunell/`.
- `router-web-ui.html` - узагальнений роутер: прокидання портів, DHCP, безпека. Має перемикач сценарію провайдера.
- `nvr-web-ui.html` - узагальнений реєстратор. Буде перезібраний з реального пристрою, коли зʼявиться доступ.

Усі три віддають свій стан сторінці курсу, тому практика перевіряється автоматично.

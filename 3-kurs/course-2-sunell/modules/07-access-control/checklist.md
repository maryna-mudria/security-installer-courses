# Чек-лист: Модуль 7

**Модуль 7 з 8** · 2 хв

Позначайте лише те, що можете зробити самі, не підглядаючи в урок.

- [ ] Можу пояснити, чим СКД в одній екосистемі з відео відрізняється від окремо стоячої СКД без зв'язку.
- [ ] Можу навести практичний приклад користі такої зв'язки на розборі інциденту.
- [ ] Можу пояснити замовнику цю користь простими словами, без термінів "інтеграція" й "платформа".
- [ ] Можу перелічити, що обов'язково внести в акт здачі об'єкта зі СКД.
- [ ] Виконав практичне завдання модуля 6.

Усі позначені - **модуль 7 з 8 закритий**. Далі практикум із типовими проблемами - перевіримо, чи вмієте ви діагностувати несправність за порядком від найпростішого рівня до найскладнішого.

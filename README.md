# Курси для інсталяторів систем безпеки

Внутрішня версія для читання. Два курси: базовий інсталятор СБ і обладнання Sunell. Практика в емуляторах у браузері, реальне обладнання не потрібне.

## Як читати

**Найзручніше (меню, емулятори, без інтернету):** відкрийте розділ Releases, скачайте `kursy-reader.zip`, розпакуйте і двічі клікніть `index.html`.

**Просто тексти на GitHub:** папка [`3-kurs`](3-kurs/). Почніть з [огляду курсу 1](3-kurs/course-1-basics/00-course-overview.md) або [курсу 2](3-kurs/course-2-sunell/00-course-overview.md). Емулятори на GitHub не запускаються, для них потрібен архів.

## Для автора

- `3-kurs/` - тексти курсів (markdown) і емулятори.
- `placeholders.json` - значення для місць `[ЗАПОВНИТИ: ...]`. Поки порожні, на сайті вони підсвічені жовтим.
- `python3 build.py` збирає сайт у `docs/` (потрібен `pandoc`). `--strict` падає, якщо лишилися незаповнені місця.
- Архів: `cd docs && zip -r ../kursy-reader.zip .`
